# Start here

This site documents **XRouter**, Paula G8PZT's packet-radio node, router, chat
server and APRS digipeater. There is a lot here, so the documentation is organised
by **what you're trying to do** rather than by feature, pick the path that matches
where you are and follow the links.

## Pick your path

<div class="grid cards" markdown>

- :material-radio-tower: **[New to packet radio](new-to-packet.md)**

    You've never run a packet station. Start with what you'll need, a licensed
    callsign, a radio, and a TNC or soundcard modem, read the
    [Packet radio basics](../basics/what-is-packet-radio.md) primers in order, then
    stand up your first node.

- :material-console: **[New to XRouter](new-to-xrouter.md)**

    You already know packet and just want XRouter running. Go straight to
    [Getting started](../getting-started/index.md), write
    [your first XROUTER.CFG](../getting-started/first-config.md), and learn what's
    distinctive about XRouter.

- :material-swap-horizontal: **[Migrating from BPQ](migrating-from-bpq.md)**

    You run BPQ/LinBPQ or other node software and want to move across or interwork.
    See what maps over, what differs, and how to link the two.

</div>

## The rest of the site, in brief

Beyond these three journeys, the navigation groups everything else by topic:

- **[Packet radio basics](../basics/what-is-packet-radio.md)**, primers on AX.25,
  NET/ROM, KISS and modems, APRS, IP over AX.25 and the sysop role. Other pages link
  back here rather than re-explaining the fundamentals.
- **[Getting started](../getting-started/index.md)**, install and first run, with a
  page per platform ([Raspberry Pi](../getting-started/raspberry-pi.md),
  [Linux PC](../getting-started/linux-pc.md), [Windows](../getting-started/windows.md)).
- **[Configuration](../configuration/index.md)**, the `XROUTER.CFG` model, the
  directive reference and worked examples.
- **[Interfaces & modems](../interfaces/index.md)** and
  **[Networking & routing](../networking/netrom-inp3.md)**, getting on the air and
  linking to the wider network.
- **[Subsystems & services](../subsystems/pms-mailbox.md)**,
  **[Operating the node](../commands/node-prompt.md)** and
  **[Administration](../admin/security-hardening.md)**, the mailbox, chat, APRS and
  built-in servers, the command set, and keeping a node healthy.
